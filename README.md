# Plantilla web corporativa editable

Esta es una versión estática y responsive inspirada en la estructura de una web corporativa de servicios digitales. Está preparada para que la edites sin dependencias ni instalación: abre `index.html` en tu navegador.

## Cambios rápidos

1. **Logo:** busca los comentarios `Reemplaza este bloque por tu imagen de logo` y `Segundo espacio reservado para tu logo` en `index.html`. Encabezado y pie se dejaron sin logo, como solicitaste.
2. **Imagen de la portada:** tu imagen está en `assets/desarrollo-web.jpeg`. Puedes sustituirla conservando el mismo nombre o editar la regla `.hero-image` en `styles.css`.
3. **Textos, datos y testimonios:** se editan directamente en `index.html`; los tres textos rotativos están al inicio de `script.js`.
4. **Contacto:** el formulario es visual y no envía datos todavía. En `script.js` hay un mensaje de demostración para que conectes tu backend, Formspree, EmailJS u otro servicio.
5. **Teléfono/correo:** cambia `+591 000 00000` y `tuemail@dominio.com` por los tuyos.

## Archivos

- `index.html`: estructura y contenido.
- `styles.css`: diseño, animación de la portada y versión móvil.
- `script.js`: menú móvil, carrusel, contadores y formulario de demostración.
- `assets/desarrollo-web.jpeg`: imagen de portada proporcionada por ti.

Para publicarlo, sube el contenido de esta carpeta a tu hosting. No requiere PHP, Node.js ni base de datos para mostrarse.
